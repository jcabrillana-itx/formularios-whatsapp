# Formularios WhatsApp - Genesys Messenger

Página estática que abre Genesys Cloud Messenger (Web Messaging) desde un botón URL enviado por WhatsApp.

URL: https://jcabrillana-itx.github.io/formularios-whatsapp/?m=prueba

Parámetros aceptados: `c` (waConversationId), `n` (nombre), `m` (motivo), `o` (origen).
Configurar `GENESYS_SCRIPT_URL`, `GENESYS_ENVIRONMENT` y `GENESYS_DEPLOYMENT_ID` en `index.html`.
